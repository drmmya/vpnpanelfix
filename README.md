# VPN PRO Admin Installer

Run from the extracted folder on a clean Ubuntu/Debian VPS:

```bash
sudo bash -c 'REPO_RAW=https://raw.githubusercontent.com/drmmya/vpnpanelfix/main bash <(curl -fsSL https://raw.githubusercontent.com/drmmya/vpnpanelfix/main/main-installer.sh)'
```

Panel URL after install:

```text
http://YOUR_VPS_IP/vpn-panel
```

Default admin:

```text
openvpn / Easin112233@
```
